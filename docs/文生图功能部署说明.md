# 文生图功能部署说明

## 概述

本项目集成 Qwen-Image-3.0 文生图 API（异步模式），通过「创建任务 + 轮询结果」的方式解决生成耗时超过云函数超时上限的问题。

## 架构说明

Qwen-Image-3.0 生成图片通常需要 1-3 分钟，而微信云函数最大超时仅 60 秒。
因此采用**异步模式**：
1. `createTask`：提交生成任务，立即返回 `taskId`（约 2-5 秒）
2. `getResult`：根据 `taskId` 轮询查询任务状态（约 2-5 秒/次）
3. 前端每 5 秒轮询一次，最多 5 分钟（60 次），状态变为 `SUCCEEDED` 后展示图片

**关键注意**：异步接口 URL 路径是 `/services/aigc/image-generation/generation`，
不是同步接口路径 `/services/aigc/multimodal-generation/generation`。

## 部署步骤

### 1. 云函数部署

#### 1.1 上传云函数
1. 右键 `cloudfunctions/text2image` → 「上传并部署：云端安装依赖（不上传 node_modules）」
2. 等待部署完成

#### 1.2 云函数超时配置
`config.json` 已设置 `timeout: 20`（秒），异步请求和轮询都是轻量 HTTP 调用，10 秒超时足够。
如仍超时，在云开发控制台手动确认：云函数 → text2image → 配置 → 超时时间设为 20 秒。

#### 1.3 配置环境变量（推荐）
1. 云开发控制台 → 云函数 → 环境变量
2. 添加：`DASHSCOPE_API_KEY` = 你的 API Key
3. 修改云函数代码中的 `DASHSCOPE_API_KEY` 为 `process.env.DASHSCOPE_API_KEY`

### 2. 小程序配置

#### 2.1 云开发环境
确保 `app.ts` 中的 `env` 值正确：
```typescript
wx.cloud.init({
  env: 'cloud1-d4gwpcu75d04fdd03',
  traceUser: true,
})
```

### 3. 云数据库集合

1. 云开发控制台 → 数据库
2. 创建集合 `images`，权限设为「所有用户可读，仅创建者可写」
3. 创建集合 `users`，权限设为「仅创建者可读写」

## 云函数接口

#### 创建任务
```javascript
wx.cloud.callFunction({
  name: 'text2image',
  data: {
    action: 'createTask',
    prompt: '提示词',
    negativePrompt: '反向提示词（可选）',
  }
})
// 返回：{ success: true, data: { taskId: 'xxx', taskStatus: 'PENDING' } }
```

#### 查询结果
```javascript
wx.cloud.callFunction({
  name: 'text2image',
  data: {
    action: 'getResult',
    taskId: '任务ID'
  }
})
// 返回：{ success: true, data: { status: 'SUCCEEDED', imageUrls: ['https://...'] } }
// status: PENDING | RUNNING | SUCCEEDED | FAILED
```

## 故障排除

### createTask 报错「不支持异步」
- 确认 URL 路径为 `/services/aigc/image-generation/generation`（不是 `multimodal-generation`）
- 确认请求头包含 `X-DashScope-Async: enable`

### 生成超时
- 异步模式下每次云函数调用只需几秒，不会超时
- 前端轮询最多 5 分钟（60 次 × 5 秒），超时后提示重试

### 首页加载失败
- 确认云数据库 `images` 集合已创建
- 确认集合权限为「所有用户可读」
